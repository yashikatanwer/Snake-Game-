# 🐍 Snake Game
A classic Snake Game developed using Python's Turtle graphics library as a project during Semester 3.

## 🎮 How to Play

Use the following keys to control the snake:

- W → Move Up
- S → Move Down
- A → Move Left
- D → Move Right

## ✨ Features

- Keyboard-controlled movement
- Food collection
- Score tracking
- Snake growth
- Wall collision detection
- Self-collision detection
- Random food placement

## 🛠️ Technologies

- Python
- Turtle Graphics
